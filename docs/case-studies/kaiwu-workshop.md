# 08 · 工作坊报名 / 文字衣橱

把长文案，折成一套能读懂的纸页。

## 设计问题

简单的课程列表与价格栏，不足以展现多类型信息的归纳能力。

## 构图与信息的关系

用三张折纸对应认识材料、制作器物、作品收尾三组任务。每页把主副标题、说明、日程、条件和提示定位；关键字段用统一标签，报名条件放在同一张底部票据。

- 大关系决定三折结构
- 同类字段形成视觉共性
- 关键信息独立定位

## 交互与细节

四段日程可展开，场次选择生成摘要；同类字段在纸页中保持相同位置与形式。

## 窄屏处理

三折纸展开为三张纵向纸页，标签职责不变；报名票据变为纵向，完整保留条件。

## 试用提示词

