# 04 · 独立香氛 / 欲擒故纵

让一缕余香，带读者走完整页。

![SŌL 桌面预览](../previews/sol-fragrance.jpg)

[打开网页](../examples/sol-fragrance/index.html) · [完整长页](../previews/sol-fragrance-full.jpg) · [手机截图](../previews/sol-fragrance-mobile.png) · [布局骨架](../previews/sol-fragrance-skeleton.jpg)

## 设计问题

产品小加大留白只能表现安静，不能体现多内容页面的减法与连贯。

## 构图与信息的关系

把内容分为闻见、停留、回响三个阶段，沿虚线曲线逐步出现。用巨大淡字、花瓣与轻量旋转建立空间支点，最后以蓝色区收束完整香调。

- 留白延长信息节奏
- 曲线与序号保持连续
- 尾部换色缓解疲劳

## 检查方法是否落实

三个阶段的试香按钮更新最后的香调档案。骨架保留连续曲线与序号，能够检查留白中的阅读路线。

## 窄屏处理

阶段改为近似纵向，保留曲线与序号；花瓣背景可裁切，香调和按钮不可隐藏。
