# 05 · 城市跑团 / 乾坤大挪移

把信息面板，旋转成一张起跑通行证。

## 设计问题

只把背景切斜，内容仍像普通运动落地页。

## 构图与信息的关系

整体旋转纸质通行证，平移其重心，在纸面上组织路线、距离与集合信息；让真实感跑者跨出纸边，与背景跑道建立前后关系。

- 整体信息平面旋转
- 人物跨越平面边界
- 路径与行动组成通行证

## 交互与细节

切换路线会更新纸上的距离和集合信息；骨架可直接辨认旋转的承载平面与人物越界区。

## 窄屏处理

跑者移到纸面上方，纸面只保留轻微角度，路线与行动继续在纸内。
